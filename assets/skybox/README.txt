Skybox face naming for MyEngine default loader:

- right.png  (+X)
- left.png   (-X)
- top.png    (+Y)
- bottom.png (-Y)
- front.png  (+Z)
- back.png   (-Z)

You can use any image format supported by stb_image (png/jpg/jpeg/bmp/tga).
From the Skybox panel, click "Use assets/skybox defaults" then "Load Skybox".
